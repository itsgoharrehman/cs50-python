# Contributing Guidelines

This repository represents completed academic coursework for Harvard University's CS50P. Because these solutions reflect graded submissions, specific constraints apply to contributions.

---

## Academic Integrity Notice

* **No Solution Alterations**: Pull requests modifying canonical solutions or adding answers to uncompleted exercises will be closed to preserve academic integrity and avoid providing shortcuts to enrolled students.
* **Permitted Contributions**: Contributions are strictly limited to documentation clarifications, typo corrections, and dependency version upgrades.

---

## Code of Conduct

All contributors and participants must adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

---

## Pull Request Process

1. Ensure the proposed change complies with academic integrity invariants.
2. Ensure no personal credentials or API secrets are introduced.
3. Open a Pull Request targeting the `main` branch and complete the academic checklist in the pull request template.
